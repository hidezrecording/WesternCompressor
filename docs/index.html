01 · The machine

One knob.
All tube.

The RCA BA-6A was a broadcast limiting amplifier: nine tubes, custom transformers, and no ratio, threshold, attack or release knobs — the circuit decided, and the engineer drove it. The Western Compressor recreates that machine at the component level: an input transformer, a 6SK7 vari-mu pair under feedback detection, 6J7 and 6V6 tube saturation stages, an output transformer, and a B+ rail that sags under load. One INPUT knob sets the drive; automatic makeup holds the programme level as the gain reduction digs in.

Vari-mu limiting

Feedback detection off the output transformer, a ratio that rises with depth, and two laws: COMP starts near 1.5:1 and digs to about 3:1; LIMIT starts at 3:1 and climbs when pushed.

Classic-centre ballistics

Attack and release toggles voiced in the middle of the classic compressors: 3 ms or 15 ms attack, 1 s single or 3 s dual release with programme memory in the slow seat.

Two-channel mix bus

COMP MIX and MOD MIX feed the output bus in parallel. The MOD send is driven post-compressor and carries reel ADT or a Phase 90, each at its natural full wet.

macOS installation

Download the latest Mac installer, then follow these steps if Gatekeeper or your DAW blocks Western Compressor.

Download Mac installer
  1. Run the installer. Download and open the .pkg file. It removes any previous Western Compressor build automatically.
  2. Approve it in Gatekeeper if macOS blocks it. Go to System Settings → Privacy & Security, scroll down, then click “Open Anyway.”
  3. Clear quarantine if your DAW still refuses the plug-in. Open Terminal and run the AU command below. For VST3, use the second command.xattr -cr ~/Library/Audio/Plug-Ins/Components/Western\ Compressor.componentxattr -cr ~/Library/Audio/Plug-Ins/VST3/Western\ Compressor.vst3
  4. Rescan plug-ins in your DAW, then load Western Compressor as an AU or VST3.
